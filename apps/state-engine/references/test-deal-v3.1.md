## Workflow Steps

1. Create deal via Detailed HL workflow
2. Enter client data (Sam + Amy Smith)
3. Save → Broker Tools tab
4. Complete Fact Find for both clients
5. Complete all sections (Assets, Liabilities, Income, Expenses)
6. Insurance + Other Advisers
7. Broker Tools → Funding Worksheet
8. Search Loan Products (3 products)
9. Compare and select preferred product
10. Commissions
11. Compliance Comments and Documents
12. Summary → Create compliance documents
13. Submit (DO NOT submit to lenders — test only)
14. Client Portal test (optional)
